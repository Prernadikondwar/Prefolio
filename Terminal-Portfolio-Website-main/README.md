Prefolio
========

Prefolio is a small static portfolio site (terminal-style and normal UI) built with HTML, CSS and JavaScript.

Quick start (serve locally):

1. Open a terminal in the project root (the folder containing `index.html`).
2. Run a simple static server (Python recommended):

   python -m http.server 8000

3. Open your browser to:

   http://127.0.0.1:8000/

   - `index.html` is the terminal-style landing page.
   - `normal/index.html` is the graphical portfolio page.

Notes:
- The repository is static — no build step required.
- Resume PDF is located at `assets/Dikondwar-Prerna-Resume.pdf`.
